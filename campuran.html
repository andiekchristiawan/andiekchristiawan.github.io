🍕 PECAHAN CAMPURAN

Apa itu Pecahan Campuran?

Pecahan campuran itu gabungan bilangan bulat + pecahan biasa.

Contoh: 2 1/2 artinya 2 + 1/2

Cara Ubah ke Pecahan Biasa:

2 1/2 = (2 x 2 + 1) / 2 = 5/2

Rumusnya: (Bulat x Penyebut + Pembilang) / Penyebut

Contoh Lain:

1 3/4 = (1 x 4 + 3) / 4 = 7/4

3 2/3 = (3 x 3 + 2) / 3 = 11/3
